# 文件命名规范

InhoDrama **不做外网刮削**，剧名、集数、封面、简介全部来自文件与目录本身。按下面的规范整理，识别率 100%。

## 一、总体结构

```
媒体库根目录/                    ← 添加媒体源时填的目录
├── 霸道总裁闪婚娇妻/            ← 每部剧一个一级子目录（目录名=剧名）
│   ├── poster.jpg              （可选）封面，识别 poster/folder/cover.jpg|png
│   ├── tvshow.nfo              （可选）简介，读取 <plot> 与 <title>
│   ├── 第01集.mp4
│   ├── 第02集.mp4
│   ├── ...
│   └── 第80集.srt              （可选）字幕，必须与对应视频同名
├── 重生之我在NAS当码农/
│   ├── poster.jpg
│   ├── 第01集.mp4
│   └── 第02集.mp4
└── 闪婚后我马甲藏不住了/
    ├── 01.mp4
    └── 02.mp4
```

要点：

1. **源目录下每个一级子目录 = 一部剧**，目录名即剧名。
2. 剧目录内的视频文件（含子目录，最多 4 层）都会被收集为单集，方便你按年份等再分文件夹。
3. 一级目录下的散装视频文件会被忽略（不算任何剧）。
4. 以 `.` 开头的隐藏目录/文件一律跳过。

## 二、集数命名（自动识别以下格式）

| 写法 | 示例 | 识别为 |
|---|---|---|
| 中文集数（推荐） | `第01集.mp4`、`第1集.mp4`、`第03话.mp4`、`第05期.mp4` | 1 / 1 / 3 / 5 |
| 纯数字 | `01.mp4`、`1.mp4`、`001.mp4` | 1 |
| EP / E 前缀 | `EP01.mp4`、`E01.mp4`、`ep-02.mp4` | 1 / 1 / 2 |
| 美剧式 | `S01E01.mp4`、`s1e12.mp4` | 1 / 12 |
| 带标题 | `第01集 霸总的的秘密.mp4`、`01.初遇.mp4`、`霸总归来 03.mp4` | 1 / 1 / 3 |

规则与建议：

1. 集数必须是 **1~4 位数字**，推荐两位补零（`第01集` 而非 `第1集`），排序更整齐。
2. **同一部剧里集数不要重复**（如同时存在 `01.mp4` 和 `第1集.mp4`）；重复时后者自动顺延一位。
3. 实在解析不出集数的文件，会排在已识别集数之后，按文件名顺序依次编号，仍可正常播放。
4. 文件名其他位置尽量避免出现 4 位以上数字（如年份写在片名里 ` dated 2024 `），以免干扰兜底解析。
5. 一集一个文件；不支持多集合一，也不支持 DVD 分卷（`-cd1`/`-part1` 会被当成两集顺延编号）。

## 三、封面

识别优先级（找到即停）：

1. 剧目录内 `poster.jpg` / `folder.jpg` / `cover.jpg` / `poster.png` / `cover.png`（大小写不敏感）
2. Jellyfin 源：直接用 Jellyfin 的海报接口
3. 系统装有 **ffmpeg**（Docker 镜像自带）：自动从第一集截取**随机一帧**（ffprobe 取时长后，在正片范围内按剧 ID 做确定性随机选点 —— 同一部剧封面稳定，不同剧取到不同画面）
4. 兜底：生成确定性配色的文字占位图

想自己控制观感就直接放一张竖版 `poster.jpg`（540×720 或 2:3 比例），随机帧只在完全没有海报文件时启用。

## 四、简介（可选）

剧目录内放 `tvshow.nfo`（Kodi/Jellyfin 通用格式），服务端读取 `<title>` 和 `<plot>`：

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<tvshow>
  <title>霸道总裁闪婚娇妻</title>
  <plot>落魄千金一夜之间闪婚神秘大佬，本以为是无爱联姻，却在朝夕相处中步步沦陷…</plot>
</tvshow>
```

Jellyfin 源的简介/流派自动取自 Jellyfin 元数据，无需 nfo。

## 五、字幕（可选）

- 与视频**同名**的 `.srt` 文件自动加载：`第01集.mp4` ↔ `第01集.srt`（也接受 `第01集.mp4.srt`）。
- 网页端：服务端自动把 SRT 转成 WebVTT 挂载。
- 安卓端：直接以 SRT 外挂轨道加载。
- Jellyfin 源的内封/外挂字幕由 Jellyfin 转码链路自行处理。

## 六、编码建议（保证网页端免转码直放）

| 项目 | 建议 |
|---|---|
| 容器 | **MP4**（网页端唯一零障碍容器；mkv/avi 在网页端走 Jellyfin HLS 或提示用 App） |
| 视频 | H.264 (AVC)，竖屏 720×1280 或 1080×1920，码率 1~3 Mbps |
| 音频 | AAC-LC，128kbps |
| 单集时长 | 短剧 1~5 分钟为宜，进度上报与自动连播体验最佳 |

批量转码一行命令（ffmpeg）：

```bash
for f in *.mkv; do
  ffmpeg -i "$f" -c:v libx264 -preset fast -crf 23 -vf scale=-2:1280 -c:a aac -movflags +faststart "${f%.*}.mp4"
done
```

> `-movflags +faststart` 把索引挪到文件头，网页端秒开拖动，强烈建议保留。
